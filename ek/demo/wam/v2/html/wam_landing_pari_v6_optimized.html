    The Project Economy

    W@M is a living art system with a creator economy around it.

    The project runs as a loop between machine composition and human performance. Music is generated, interpreted, performed, and redistributed as new cultural signal.

    Its economy is participation-led: creators, performers, editors, and curators all add value to each release cycle.

    Revenue flows through releases, tickets, licensing, commissions, and collaborations. Value is shared across the vessel network that brings W@M into the physical world.

    Protocol: create, perform, publish, reinvest, repeat.

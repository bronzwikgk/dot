# action3d-viewer

Interactive 3D model viewer using `<model-viewer>`.

## Structure

- `index.html` - Viewer page (GitHub Pages entrypoint).
- `assets/models/` - GLB model assets used by the dropdown.

## Models

- `sheen-chair.glb`
- `alira-range-02.glb`
- `aquaclick-thermostat.glb`
- `aquaclick-thermostat-duplicate.glb` (same content as `aquaclick-thermostat.glb`)

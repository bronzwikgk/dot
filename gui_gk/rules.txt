Critical Rules for this model:

A ContentCollection CANNOT contain a ContentCollection. Only Blocks.

A ContentBlock CANNOT contain a ContentBlock. Only Cells.

ContentCell is the absolute leaf node. It contains ONLY text and inline styles.

The semantic object inside ContentBlock is how we enable Kanban/Calendar views later.

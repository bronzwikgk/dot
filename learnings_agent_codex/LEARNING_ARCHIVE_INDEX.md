## Use Policy

- Treat this folder as learning/reference history.
- Do not treat this archive as the active source of truth when it conflicts with `dot/docs/an_app_master_project`.
- When adopting from this archive, create or update the relevant active doc, dataset, utility, plugin, schema, test, and log in the main `dot` structure.
- Keep new implementation work outside this archive unless explicitly preserving historical learning material.

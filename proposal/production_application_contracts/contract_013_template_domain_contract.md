# Contract 013: Template Domain

Status: proposed
Priority: p1
Owner domain: template_domain

## Purpose

Define governed templates and sample pipelines for business application creation.

## Required Template Families

- LMS
- fintech organization
- single user
- stock trading research
- website
- product workspace
- research agent
- team of agents
- document
- workflow

## Required Records

- template
- template_slot
- default config
- sample input
- expected artifact
- validation report
- domain mapping

## Validation

- slot names are approved
- generated entities match schemas
- domain names are approved
- template output passes artifact checklist
- examples include success and failure cases

## Success Criteria

- user can create a website
- user can create a product workspace
- user can create notebook/book
- user can create automation schedule
- user can create research/team agent plan
- user can create fintech/trading sample workspace

## Do Not

- do not create templates without sample inputs and expected outputs

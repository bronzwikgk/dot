# User Data

## Purpose

Store user-created or user-imported working data that is not project doctrine,
contract, code, or approved app data yet.

## Rules

- user data must not become active app behavior until validated and promoted
- imported files should keep provenance and source path
- sensitive or private content must not be copied into docs unless the user
  explicitly asks
- promoted data must move through app data, docs, templates, or code according
  to its approved shape
